# Wiki images

This folder contains the twelve original PNGs reused from the owner's Spigot description. They are byte-for-byte copies of the linked Imgur images, with descriptive local filenames.

The [image placement guide](../../image-placement-guide.md) records each source URL, filename and wiki page. Keep those records current when replacing or adding screenshots.

Only link an image once its file exists. Screenshots belong to the documentation and are not included in the plugin JAR or runtime resource packs.
