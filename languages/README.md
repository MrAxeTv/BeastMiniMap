# BeastMiniMap language files

Snapshot: `languages-98df6c8fad8ccb41`. All 50 translations are maintained together; 33 European/US-English files are bundled and 17 are optional downloads.

Select a filename with `Options.Language.Settings.File` in `config.yml`. Selecting an optional file downloads its matching defaults in the background when `Options.Language.Settings.AutoDownload: true` (the default). Set it to `false` for manual installation. For manual installation, download the YAML into `plugins/BeastMiniMap/Lang/`, keep its filename, then run `/beastminimap reload` or restart normally. Existing local edits are preserved. English `en-US.yml` remains the default and fallback.

Use the language snapshot matching the plugin build. [Browse this snapshot](https://github.com/MrAxeTv/BeastMiniMap/tree/languages-98df6c8fad8ccb41/languages). File hashes and byte sizes are in `catalog.properties` and `SHA256SUMS.txt`.

Translations are machine-assisted and are not native-speaker certified. Preserve keys, placeholders, command syntax and formatting when editing. Chat and native dialogs support Unicode; use `Atlas.MenuUi: native` where the compact map font cannot display a script, and retain Latin text for the atlas header.

Future message changes must update all 50 source translations and pass the full language-integrity audit before publishing a new content-derived snapshot. Keep existing snapshot tags available so older builds can download matching files.
